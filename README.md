# King Soon Bot

บอท Discord สำหรับร้านค้า King Soon พัฒนาด้วย Python โครงสร้างเริ่มต้นนี้เตรียมไว้สำหรับต่อยอดระบบร้านค้าในภายหลัง

## เริ่มใช้งาน

1. ติดตั้ง Python 3.10 หรือใหม่กว่า
2. สร้างและเปิดใช้งาน virtual environment (แนะนำ)
3. ติดตั้งไลบรารี:

   ```powershell
   pip install -r requirements.txt
   ```

4. คัดลอก `.env.example` เป็น `.env` แล้วใส่ Discord bot token ของคุณใน `DISCORD_TOKEN`
5. ในหน้า Developer Portal ของ Discord ให้เปิด **Message Content Intent** สำหรับบอท
6. เริ่มบอท:

   ```powershell
   python bot.py
   ```

เมื่อบอทออนไลน์แล้ว ลองใช้คำสั่ง `ks!ping` เพื่อทดสอบการตอบกลับ

## แผงติดต่อแอดมิน

แอดมินใช้ `/ตั้งค่า-แผงติดต่อ` เพื่อสร้างแผงในช่องปัจจุบันครั้งแรก จากนั้นใช้ `/แก้ไข-แผงติดต่อ title: description: image_url:` เพื่อปรับข้อมูลของแผงเดิมโดยไม่สร้างข้อความซ้ำ

การเลือกหัวข้อจะสร้าง ticket ที่มีเฉพาะผู้เปิด ticket ทีมแอดมิน และบอทเข้าถึงได้ ดังนั้น role ของบอทต้องมีสิทธิ์ **Manage Channels**

ก่อนให้สมาชิกเปิด ticket แอดมินต้องใช้ `/ตั้งค่า-หมวดหมู่ติดต่อ` และเลือก Category ที่ต้องการให้บอทสร้าง ticket ภายใน ระบบจะบันทึกทั้งหมวดหมู่ ข้อมูลแผง และตำแหน่งข้อความแผงแยกตามเซิร์ฟเวอร์ไว้ใน `ticket_settings.json` จึงใช้งานแผงเดิมต่อได้แม้บอทรีสตาร์ต

> ห้ามส่งหรืออัปโหลดไฟล์ `.env` เพราะมี token ลับของบอท
